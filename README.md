# Sabji Bhaji — Indian Sabji & Bhaji Landing Page

A responsive, mobile-first landing page for an India-focused fresh vegetables / sabji business. Built with plain HTML and CSS—no build tools, dependencies, or computer required.

## Preview locally
Open `index.html` in any browser.

## Deploy using only your phone (GitHub + Netlify)
1. Open **github.com** in Safari/Chrome and sign in (or create an account).
2. Tap **+ → New repository**. Name it `sabji-bhaji`, choose Public, and create it.
3. In the repository, tap **Add file → Upload files**. Upload `index.html`, `style.css`, and `README.md` from this project ZIP (extract it on your phone first).
4. Open **netlify.com** in your phone browser and sign in with GitHub.
5. Choose **Add new site → Import an existing project → GitHub**, select `sabji-bhaji`, then deploy. Your live URL will look like `https://....netlify.app`.

Alternative: use **vercel.com** → Sign in with GitHub → Add New Project → import the repo → Deploy.

## Customize before publishing
- Replace the WhatsApp number `919999999999` in `index.html` with your number (country code, digits only).
- Update sample vegetable prices and units in `index.html`.
- Replace brand name Hariyali and copy as desired.
- This is a landing page/demo, not a checkout or live inventory system.
